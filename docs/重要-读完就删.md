## 四、上一轮的实测结论(一句话版)

- **有一条已订阅路由 `qwen-token-plan-cn`,边际成本 = 0**。它提供 **16 个能跑工具调用的模型**,
  包括 `qwen3.7-plus` / `glm-5.3` / `deepseek-v4-pro` / `kimi-k3` / `MiniMax-M2.5`。
  ⇒ **子智能体的活尽量塞这里。**
- **主智能体不换**(继续 `deepseek-official/deepseek-flash`,`high`)。判断质量是最贵的东西。
- **千帆兜底最便宜的是 `glm-5.3-flash`(0.8 / 2.8 元每百万)**;
  `deepseek-v4.1-flash`(1.2 / 4.8,缓存读 0.024)是兜底首选。
- **`qwen-token-plan-individual` 是死的**(实测 401,同一个密钥打 dashscope 端点却是好的)⇒ **别加**。
- **`kimi-k3` 在 Moonshot 账号下无权限**;Moonshot 实际只有 `kimi-k2.6` / `kimi-k2.7-code`。
- **两个坑**:① `reasoning_effort` 不能一律填 `high`(`qwen3.8-*` 没有 high;`qwen3.7-plus`/`kimi-*` 根本不支持推理参数);
