# 手稿（扫描/拍照归档）

> 这里放项目相关的手写稿、草图、白板照。**原图不在 git 之外**：原图和转录一起提交，宁可仓库大一点，
> 也别让"字只存在于某人的手机里"。

## 约定

- 一个日期一个文件夹：`docs/手稿/YYYY-MM-DD/`
- 原图命名：`页NN.jpg`（按到达/拍摄顺序，不重命名成语义名，避免以后对不上）
- 同一张纸拍了多张的，在转录文档里注明"哪几张是同一张"，别当成多页
- 转录文档：`手稿转录.md`，**逐字转录，不改写、不补内容**；认不准写 `〔？〕`
- 转录里用的 `#`/`-`/表格是排版，不属于原文
