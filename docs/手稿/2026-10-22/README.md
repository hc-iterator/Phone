## 本次对流水线工具的改动

`tools/manuscript/mosaic.py` 新增**亮度增益对齐**：贴回前按重叠区均值，把每块局部近拍的曝光拉到底图同一基准上。
基准取**未改动的 `canvas`**（不是累加的 `acc`），这样每块都对齐同一个底，不会链式漂移。日志会打印 `亮度增益 BGR = ...`。

原因：脚本原本已有「腐蚀 + 高斯羽化」，几何接缝处理得不错，但**羽化只能抹平几何接缝，抹不掉三张照片曝光不同造成的亮度台阶**。
首次成品就是「一块正常、两块偏暗」的矩形分区，观感很差。

实测增益：页02 ≈ **1.18**、页03 ≈ **1.00**、页04 ≈ **1.22** —— 与肉眼判断一致（页02/页04 偏暗）。
对齐后三块亮度台阶基本消失，仅页04 左边界残留一条很淡的竖线。
