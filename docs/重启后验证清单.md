# 重启后验证清单（项目库 / 计时器 / 记忆库状态）

> 目的：一次重启只做一次验证，别反复重启。
> 用法：重启完成后逐条执行，把结果写回本文件末尾的「最近一次验证」。

## 一、插件是否都激活了

**先说明**：实测 `%DSH_HOME%\logs\` 里最新的启动日志是 2026-11-06 的，**今天的启动没有落盘**
（当前 DSH 只在控制台/渠道消息里打印）。所以验证顺序改成：
1. **首选**：看微信/渠道里那条启动消息（形如 `dsh: warning: N entries did not activate` + 具体报错）；
2. 其次：工具是否出现在列表（下面第二节）；
3. 只有在 `logs/` 里存在**当天**的 `startup-*.log` 时，才用下面这条命令。

1. 不应出现 `did not activate`；
2. 不应出现 `already registered`；
3. 不应出现 `@local/dsh-timer): Error`。

```powershell
Get-ChildItem 'C:\固态盘秘钥\.dsh\logs' -Filter 'startup-*.log' |
  Sort-Object LastWriteTime -Descending | Select-Object -First 1 |
  ForEach-Object { Select-String -Path $_.FullName -Pattern 'did not activate|already registered|\): Error' }
```
期望：**无输出**。

## 三、冒烟三问（用工具，不用命令行）

1. `proj_get({subject:"PSRAM", attribute:"max_sel"})` ⇒ 应返回 **18**，出处 `当前状态.md:162`；
