## 二、派活规则

1. **要动台架（编译/烧写/串口/SWD）** ⇒ 只派 `PicoMode`、`PicoMode(1)`、`PicoModeTest`；
2. **只改代码/文档/做分析** ⇒ 可派 `PicoPhone`（标准）、`PicoPhoneCreate`（创造）；
3. **作业帮、打印机驱动** 与 Pico 无关，不塞 Pico 任务；它们自己的活自己排；
4. **重启权限** 属用户与审批员，项目经理不请求、不施压、不走捷径；
5. 派活信息必须含：**范围 + 验收标准 + 回执方式**（回 `agent_send` 给项目经理）。
