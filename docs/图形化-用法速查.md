# 图形化能力 · 用法速查

一页纸。给任何会话看：**要操作桌面窗口时，按这个顺序选工具**。

## 0. 先判断该用哪一层

```
能在网页里点 → gui_browser（CDP，最准）
有原生控件   → gui_uia（不动鼠标、不抢焦点）
都没有       → gui_click（坐标注入，会抢焦点）+ gui_verify
```

## 1. 看有哪些窗口

```js
gui_windows()
// → hwnd / 进程 / 尺寸@位置 / 标题
```

## 2. 截图（先看再动）

```js
gui_capture({ hwnd: "0x3049A", maxWidth: 900 })
```

- 想看清某个细节（小字、细线）：`gui_zoom({ x, y, size: 100, scale: 4 })`
- 大图看不清时**不要去猜坐标**，先 zoom

## 3. 虚拟屏：让窗口不出现在用户眼前

```js
gui_vdd({ action: "status" })   // 看有没有 DISPLAY19
gui_launch({ file: "notepad.exe" })   // 启动并自动挪到虚拟屏（不抢焦点）
gui_place({ hwnd: "0x..." })          // 已在主屏的窗口挪过去
```

⚠️ 虚拟屏**不要频繁插拔**：每插一次 Windows 会重排所有窗口，用户会看到"到处弹窗"。
keeper 有启用开关（`%TEMP%\picophone-vdd.enable`），开着就别动它。

## 4. 找控件

**网页 / Electron**（浏览器要用 `--remote-debugging-port` 启动）：

```js
gui_browser({ cmd: "tree", port: 9333 })
// → 每个可点元素的 selector / 文本 / 精确矩形
```

**原生程序**：

```js
gui_uia({ hwnd: "0x...", cmd: "tree", onlyClickable: true })
// → 每个控件的 type / name / AutomationId / rect / 是否可点
```

## 5. 动作（按安静程度排序）

```js
// ① 最安静：UIA 直接触发，不动鼠标、前台不变
gui_uia({ hwnd: "0x...", cmd: "invoke", automationId: "num7Button" })
gui_uia({ hwnd: "0x...", cmd: "invoke", name: "确定" })
gui_uia({ hwnd: "0x...", cmd: "invoke", automationId: "inputBox", method: "value", value: "hello" })

// ② 网页
gui_browser({ cmd: "click", port: 9333, selector: "#submit" })
gui_browser({ cmd: "type",  port: 9333, selector: "#name", text: "Pico" })

// ③ 兜底：坐标点击（会动真实鼠标、需要窗口在前台）
gui_click({ x: 2000, y: 300 })
```

自绘 UI（没有控件树、没有 DOM）还可以按颜色找：

```powershell
pwsh -File tools/gui/find-color.ps1 0x1234 '#005a9e' -Tolerance 20
# → 每个色块的中心点，拿来给 gui_click
```

## 6. 必须证明动作生效

```js
gui_verify({ hwnd: "0x...", command: "pwsh -File tools/gui/click-at.ps1 2000 300" })
// → changed 0.276% / unchanged   ← 明确结论，不要自己假设成功
```

更好的校验：如果应用暴露了文本（如计算器的 `CalculatorResults`、网页的 `#out`），
**直接读文本**比像素比对更可靠：

```js
gui_browser({ cmd: "eval", port: 9333, script: "document.getElementById('out').textContent" })
```

## 7. 已知坑（别重复踩）

| 现象 | 原因 | 处理 |
|---|---|---|
| 截图全黑 + 屏幕截取得到**桌面壁纸** | 窗口 cloaked（别的虚拟桌面/挂起） | 工具会直接拒绝；换个桌面再抓 |
| 打字成功但截图没变 | WinUI3 的 PrintWindow 返回**旧帧** | 用 `-PreferScreen`（校验器自动判断） |
| `[place] 挪动没生效` | 目标提权（regedit/mmc） | 别挪它，或让 DSH 提权 |
| 点按钮有高亮但菜单不出 | 未解（怀疑按下即开/飞窗非标准 HWND） | 优先用键盘或 UIA 菜单项 |
| Chromium 只有 `Chrome Legacy Window` | 网页内容不暴露给 UIA | 走 CDP |
