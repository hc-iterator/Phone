## 三、容易混的"一对词"（听错一个意思就反了 ✗）

| 容易混 | 分清 |
|---|---|
| **特权态 / 非特权态** | privileged vs unprivileged；`CONTROL.nPRIV` |
| **PSP / MSP** | 应用栈 vs 内核栈 |
| **MMFAR / CFSR** | 出错地址 vs 错误状态 |
| **上机 / 主机侧** | 【上机】= 真板实测；【主机侧】= PC 桩环境 |
| **探针 / DUT** | 调试器那块 vs 被测那块 |
| **RBAR / RLAR** | MPU 区域基址 / 上限（ARMv8-M 命名）|
| **后面 / 后门** | 语音常把「后门」识别成「后面」✗ ⇒ 语境是「烧写 / 救回来」时一律按**后门**理解 ✓ |
