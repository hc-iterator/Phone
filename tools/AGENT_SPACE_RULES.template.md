# 子智能体空间规则（主 AI 设定，必守）

## 这是什么
这是【你自己的独立 git 仓库】，是主仓库 DeepSeekCode 的一份**克隆**。
你在这里做的任何改动、任何提交，都只落在本目录里。

## 硬边界（违反 = 任务失败）
1. **绝对不要读写主仓库** `C:\Users\Chen\Desktop\Pico\PicoPhone\DeepSeekCode\`，
   也不要碰 `C:\Users\Chen\Desktop\Pico\PicoPhone\UserCode\`。
   你的活动范围**只有本目录**。
2. 本仓库**没有 remote**（主 AI 已经摘掉）—— 不要 `git push`，不要 `git remote add`。
   主 AI 会自己来取你的提交。
3. 你的工作分支：`agent/<你的名字>`。不要切到别的长期分支。
4. 不要动 `third_party/` 下的第三方库，除非任务说明**明确允许**。
5. 不要联网下载/安装任何东西（装包必须先问，本项目规矩 6）。

## 交付方式
- 每完成一个**可验证**的小步就本地 commit，不要攒到最后。
  （这条还有第二个用处：主 AI 靠它判断你到底有没有开始干活。）
- commit message 用中文，写清：做了什么 + 为什么 + **验证判据是什么**。
- 结束时在回复里给：分支名 / commit 列表（短 hash + 标题）/ 跑过的命令与结果 /
  **没做到的、存疑的、以及你推翻了的假设**。

## 本项目必读（按顺序，读完再动手）
1. `docs/开工前自检.md`   ← 唯一入口，约 1 分钟
2. `docs/导引.md`
3. `docs/需求.md`
4. `docs/工作守则.md`
5. `docs/当前状态.md`

> 项目头号风险是"**记混了**"，不是技术难。
> **没实测的必须标"待验证"，不许写成结论**（`docs/工作守则.md` §二）。
