# 反汇编 / 反编译（约 25 个工具）

**能干什么**：伪代码、函数恢复、控制流。

**什么时候用**：要读懂二进制逻辑、把汇编还原成类 C 伪代码时。

**怎么加载**：调用 	ools_load('rea-disasm') —— 只会把这一组工具注册进当前会话。
用完可 	ools_unload('rea-disasm')；默认 **10 分钟无调用会自动卸载**。
